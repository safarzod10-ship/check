# Состояние проекта (версия 0.1.0)

Честный список: что сделано и как именно проверено.

## Проверено автоматическими тестами на настоящем сервере

`./gradlew :core:test` — 17 сквозных сценариев против локального Supabase (Postgres, Auth, Realtime, Storage),
без подмен; коды подтверждения берутся из реально отправленных писем:

- регистрация двух пользователей по коду из письма, уникальный Payvan ID
- неверный код, неверный пароль, неподтверждённая почта, повторная регистрация
- уникальность и проверка имени пользователя; поиск по имени и Payvan ID
- сохранение сессии после «перезапуска», выход, повторный вход
- переписка в реальном времени, статусы отправлено → доставлено → прочитано, счётчик непрочитанных,
  ответы, отсутствие дубликатов при повторной отправке, таджикская кириллица
- редактирование и удаление (только своих сообщений)
- фото, голосовое, пересылка с файлом; посторонний не видит сообщения и не скачивает файлы; лимит 20 МБ
- аватар
- группа: участники, администраторы, права, исключение, передача владения
- публичный канал: поиск, вступление, запрет писать подписчикам
- блокировка и жалоба
- прямые поддельные REST-запросы (подмена отправителя, самовольное вступление, правка чужого профиля, anon-доступ)
- восстановление пароля по коду из письма
- ограничение частоты сообщений
- недоступный сервер даёт ошибку сети, а не падение
- удаление аккаунта

## Проверено вручную в эмуляторе Android 9 (API 28)

Отладочная и релизная (R8) сборки, второй пользователь — отдельный клиент через тот же сервер:

- первый запуск, выбор языка, интерфейс на русском и таджикском
- регистрация с кодом из письма, заполнение профиля, выдача Payvan ID
- восстановление сессии после перезапуска приложения (шифрованное хранилище)
- список чатов: появление чата и группы в реальном времени, счётчик непрочитанных, статус «в сети», время
- чат: входящие текст и фото (загрузка из закрытого хранилища), отправка текста, смена галочек на «прочитано»,
  меню по долгому нажатию, редактирование сообщения
- групповой чат, системные сообщения
- вкладки «Сообщества» (включая список публичных каналов) и «Профиль»
- вход в аккаунт в релизной сборке

Найдено и исправлено при этой проверке: падение сразу после входа, курсор и фокус при редактировании,
цвет системной панели и заголовков в тёмной теме, имя отправителя в группе, форма логотипа.

## Написано, но на устройстве НЕ проверено

Серверная часть этих функций покрыта тестами выше, но экраны и работа с «железом» не прогонялись:

- отправка фото, видео и документов из приложения (системный выбор файлов)
- запись и воспроизведение голосовых сообщений (в эмуляторе нет микрофона)
- ответ, пересылка и удаление через интерфейс; просмотр фото на весь экран
- создание группы/канала и экран информации (участники, роли, добавление)
- блокировка и жалоба через интерфейс; восстановление пароля и удаление аккаунта через интерфейс
- светлая тема (кроме первых экранов), смена языка и темы в настройках
- нажатие на уведомление
- работа на реальных телефонах и на Android 10–15, поведение на медленной мобильной сети
- **push через FCM** и Edge Function `push` — не запускались ни разу (нужен проект Firebase)
- облачный Supabase — тесты шли на локальном стеке той же версии ПО

## Не реализовано

- голосовые, видео- и групповые звонки (есть проект, см. ARCHITECTURE.md)
- сквозное шифрование
- подтверждение телефона по SMS (платно у всех провайдеров)
- локальная база для чтения переписки без сети
- сжатие видео, превью видео, отправка с камеры
- синхронизация телефонной книги, поиск по сообщениям, индикатор «печатает…», реакции
- панель модератора для жалоб
- вход через Google / Apple / Telegram (на вашем макете есть такие кнопки — в приложении их нет, потому что они не работали бы)
