# DUSHANBE-X

Мобильная игра с открытым 3D-миром для Android на **Godot 4.4.1**, вдохновлённая Душанбе,
Варзобским ущельем, Гиссарской долиной и горами Таджикистана. Мир — оригинальная игровая
интерпретация: собственная карта, собственная архитектура, всё построено процедурно в 3D.

* [Дизайн мира и карта](docs/WORLD_DESIGN.md) · [Архитектура](docs/ARCHITECTURE.md) · [Отчёт о тестировании](docs/REPORT.md)
* Скриншоты — `docs/screenshots/`

## Что есть в мире

* **100 км²** (10×10 км), рельеф с шагом 5 м: хребты до 2357 м со снегом, ущелья, долины, котловины.
* **Душанбе** — 5 районов, 196 км дорог (проспекты, бульвары, улицы, мосты, перекрёстки, светофоры, зебры),
  ~5800 зданий 9 архетипов (хрущёвки, панельки, башни, сталинки, магазины, хавли, школы, сельские дома),
  19 достопримечательностей в 3D: памятник Сомони и площадь Дусти, флагшток 165 м, Дворец Наций, парк Рудаки,
  Национальный музей и библиотека, театр Айни, Кохи Навруз, Мехргон, Исмаилитский центр, Дворец Вахдат, ТНУ,
  медуниверситет, Парк Победы, вокзал, Гиссарская крепость, медресе Кухна, смотровая Сафеди Варзоб.
* **Варзоб** — река, трасса с тоннелем 520 м, кишлаки, водопады, кафе, турбазы, серпантин на плато.
* **Гиссар и сельская местность** — поля (пшеница, хлопок, люцерна, пашня), абрикосовые сады, виноградники,
  каналы, кишлаки с дувалами и айванами, рынки, чайханы, АЗС.
* **Природа** — 8 видов деревьев и кустов, валуны, трава с цветами, реки, ручьи, озёра, водопады с брызгами.
* **Атмосфера** — смена дня и ночи, рассвет и закат, звёзды и луна, облака, туман, дождь, гроза,
  мокрые дороги с лужами, огни города и окна ночью.
* **Игра** — персонаж со скелетом (22 кости, 23 анимации), ходьба, бег, прыжок, присед, ближний бой;
  9 типов машин с физикой, посадка и выход, угон; трафик, автобусы, такси, полиция и розыск, пешеходы;
  заправки, магазины и чайханы, задания доставки, случайные события, открытие достопримечательностей.
* **Интерфейс** — сенсорный стик и кнопки, миникарта, полная карта с быстрым перемещением,
  пауза, настройки графики (Низкие / Средние / Высокие / Ультра), время и погода.

## Управление

| Действие | Сенсорный экран | Клавиатура |
|---|---|---|
| Движение | левый плавающий стик | WASD / стрелки |
| Камера | перетаскивание справа | правая кнопка мыши |
| Прыжок / бег / присед | ПРЫЖОК / БЕГ / ПРИСЕСТЬ | Пробел / Shift / C |
| Удар | УДАР | F |
| Действие (заправка, еда) | ДЕЙСТВИЕ | E |
| Сесть / выйти | СЕСТЬ / ВЫЙТИ | G |
| Газ / тормоз / руль | ГАЗ / ТОРМОЗ / ◀ ▶ | W / S / A D |
| Ручник / сигнал | РУЧНИК / СИГНАЛ | Пробел / H |
| Карта / пауза | миникарта / ⏸ | M / Esc |

## Сборка

Требуется Godot 4.4.1, Python 3 с `numpy`, `scipy`, `pillow`; для APK — Android SDK (build-tools 34, platform 34),
JDK 17+ и шаблоны экспорта Godot 4.4.1.

```bash
# 1. сгенерировать мир и текстуры (данные уже лежат в репозитории; шаг нужен только после правок раскладки)
python3 tools/worldgen/texgen.py
python3 tools/worldgen/worldgen.py          # ≈70 с: data/heightmap.f32, world.json, карты, docs/world_map.png

# 2. импорт и запуск на ПК
godot --path . --import
godot --path .

# 3. APK (в настройках редактора указать export/android/android_sdk_path, java_sdk_path, debug keystore)
godot --headless --path . --export-debug "Android" build/DUSHANBE-X-debug.apk
```

Для релиза нужен собственный keystore (Project → Export → Android → Keystore/Release).

## Режимы тестирования

```bash
# скриншоты мира с заданных камер (без игрока)
godot --path . -- --shots=res://tools/shots/final.json --preset=high
# игровой прогон с игроком, HUD и действиями + профилирование нагрузки по системам
godot --path . -- --gameshots=res://tools/shots/game1.json --preset=medium
# отдельные тесты модулей
godot --path . res://vehicles/test/vehicle_test.tscn -- --mode=drive
godot --path . res://characters/test/character_test.tscn
godot --headless --path . -s res://world/landmarks/test_build.gd
```

## Структура

```
autoload/      WorldData, GameSettings, TimeWeather, GameState
scenes/        main.tscn — точка входа, подключение систем, тестовые режимы
world/terrain  стриминг рельефа (5 LOD), шейдер поверхности
world/roads    дороги, тротуары, мосты, тоннель, разметка, зебры
world/water    реки, озёра, водопады
world/city     генератор зданий, стриминг города, окклюдеры
world/landmarks достопримечательности и придорожные объекты (по файлу на объект)
world/nature   деревья, кусты, камни, сады, виноградники, трава
world/props    фонари, светофоры, остановки, знаки, щиты, ЛЭП
world/environment небо, солнце/луна, туман, дождь
world/events   сервисы, задания, случайные события
characters/    скелетный гуманоид, анимации, игрок, камера, пешеходы
vehicles/      модели машин, физика, трафик, полиция, парковки
ui/            HUD, сенсорное управление, миникарта, карта, меню, настройки
audio/         синтезированные звуки и система эмбиента
tools/         генераторы мира/текстур/звука, сценарии скриншотов
data/          сгенерированные данные мира
```
