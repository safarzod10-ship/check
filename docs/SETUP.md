# Настройка сервера PAYVAND

Приложению нужен сервер. Бесплатный вариант — облачный проект Supabase; тот же код работает и на
self-hosted Supabase на собственном сервере.

## 1. Проект Supabase (регистрация нужна вам лично)

1. Зарегистрируйтесь на https://supabase.com и создайте проект (регион ближе к пользователям, например Frankfurt).
2. Примените схему. Любой из способов:
   - **Через сайт:** SQL Editor → вставить целиком `supabase/migrations/20261113000000_payvand_init.sql` → Run.
   - **Через CLI:** `supabase link --project-ref <ref>` → `supabase db push`.
3. Project Settings → API: скопируйте **Project URL** и **anon / publishable key**.
   Ключ `service_role` / `secret` в приложение не вводится никогда: сборка и экран подключения его отклоняют.

Миграция создаёт таблицы, политики RLS, серверные функции, бакеты `avatars` (публичный, до 2 МБ) и
`media` (закрытый, до 20 МБ на файл) и включает Realtime для `messages` и `members`.

## 2. Авторизация по почте

Authentication → Sign In / Providers → Email:
- **Confirm email** — включить.
- Минимальная длина пароля — 8.

Authentication → Emails → шаблоны **Confirm signup** и **Reset password**: замените содержимое на
`supabase/templates/confirmation.html` и `recovery.html`. Главное — в письме должен быть `{{ .Token }}`
(6-значный код), а не ссылка: приложение просит ввести код.

### Почтовый сервер (обязательно для реальных пользователей)
Встроенная почта Supabase предназначена только для проверки: жёсткий лимит писем в час и ограничения на адресатов.
Подключите свой SMTP в Authentication → Emails → SMTP Settings. Бесплатные тарифы на момент подготовки
(проверьте актуальные условия): Brevo — около 300 писем в день, Resend — около 100 в день.
Для хорошей доставляемости нужен собственный домен (это единственная вероятная трата: ~10–15 $ в год).

### Почему не SMS
Бесплатной отправки SMS не существует. Firebase Phone Auth с 2024 года требует платёжный аккаунт (тариф Blaze)
и берёт плату за каждое SMS; Supabase Phone Auth работает через платных провайдеров (Twilio и др.).
Поэтому регистрация — по email, а номер телефона пользователь может указать в профиле (он помечен как
неподтверждённый и виден только владельцу). Когда появится бюджет, подтверждение по SMS включается в Supabase
без переделки базы.

## 3. Push-уведомления (необязательно, бесплатно)

Без этого шага уведомления приходят, только пока приложение запущено или недавно свёрнуто.

1. https://console.firebase.google.com → создать проект → добавить Android-приложение с пакетом `tj.payvand.app`.
2. Из `google-services.json` возьмите значения и задайте при сборке (в `local.properties` или секретах CI):
   `PAYVAND_FCM_APP_ID` (mobilesdk_app_id), `PAYVAND_FCM_API_KEY` (current_key),
   `PAYVAND_FCM_PROJECT_ID` (project_id), `PAYVAND_FCM_SENDER_ID` (project_number).
3. Firebase → Project settings → Service accounts → Generate new private key (JSON). Это секрет сервера:
   ```bash
   supabase secrets set FCM_SERVICE_ACCOUNT="$(cat service-account.json)" PUSH_WEBHOOK_SECRET="<случайная строка>"
   supabase functions deploy push --no-verify-jwt
   ```
4. Supabase → Database → Webhooks → Create: таблица `messages`, событие INSERT, тип HTTP Request,
   URL `https://<ref>.supabase.co/functions/v1/push`, заголовок `x-payvand-secret: <та же строка>`.

> Эта часть написана по документации и **не проверялась на реальном проекте Firebase** (см. docs/STATUS.md).

## 4. Используемые сервисы и лимиты бесплатных тарифов

Цифры собраны из открытых обзоров в ноябре 2026 г.; источники расходятся в деталях — сверяйте с
https://supabase.com/pricing и https://firebase.google.com/pricing перед запуском.

| Сервис | Для чего | Бесплатно (ориентировочно) | Что случится при превышении |
|---|---|---|---|
| Supabase Database | профили, чаты, сообщения | 500 МБ | проект переводится в режим «только чтение» |
| Supabase Auth | аккаунты | 50 000 активных пользователей в месяц | нужен платный тариф |
| Supabase Storage | фото, видео, файлы, голосовые | 1 ГБ всего | загрузки перестают работать |
| Supabase egress | трафик | 5 ГБ в месяц (в части источников — 10 ГБ) | ограничения до следующего месяца |
| Supabase Realtime | доставка в реальном времени | ~200 одновременных подключений | новые подключения отклоняются |
| Supabase Edge Functions | отправка push | ~500 000 вызовов в месяц | — |
| Firebase Cloud Messaging | push | бесплатно | — |
| SMTP (Brevo / Resend) | письма с кодами | ~100–300 писем в день | письма не уходят |

Важно:
- Бесплатный проект Supabase **приостанавливается после 7 дней без активности** (возобновляется вручную в панели).
- 1 ГБ хранилища — это примерно 5 000 фото после сжатия в приложении или 50 видео по 20 МБ. Первым закончится именно хранилище.
- ~200 одновременных подключений — реальный потолок бесплатного тарифа по числу людей онлайн.
- Тариф Pro — около 25 $ в месяц. Бесконечной бесплатной работы не будет.

## 5. Локальный сервер для разработки и тестов

```bash
supabase start            # нужен Docker; письма попадают в Mailpit: http://127.0.0.1:54324
export PAYVAND_TEST_URL=http://127.0.0.1:54321
export PAYVAND_TEST_ANON_KEY=<anon key из вывода supabase start>
export PAYVAND_TEST_MAIL_URL=http://127.0.0.1:54324
./gradlew :core:test      # 17 сквозных сценариев + модульные тесты
```
Отладочная сборка приложения в эмуляторе подключается к локальному серверу по адресу `http://10.0.2.2:54321`.
